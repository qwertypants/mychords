# Extended guitar chords

MyChords adds `m13`, `m11add13`, `7add13`, `maj7add13`, `m7add13`, `add13`, `madd11`, and `madd13` in all 12 roots. Search accepts spaces and parentheses around additions: `Bm11 add 13`, `Bm11(add13)`, and `Bm11add13` select the same chord. Complete symbols take precedence over partial matches; a bare root continues to show all its qualities.

## Sources and naming

- [Open Music Theory: chord symbols](https://viva.pressbooks.pub/openmusictheory/chapter/chord-symbols/) supplies the notation reference.
- [Open Music Theory: jazz voicings](https://viva.pressbooks.pub/openmusictheory/chapter/jazz-voicings/) discusses omitted tones. The application makes its own explicit required-tone choices below.
- [Tonal chord dictionary](https://tonaljs.github.io/tonal/docs/dictionaries/chord-types/) supplies independently maintained base formulas and interval arithmetic. Pinned MIT packages are development dependencies; no library or external lookup is needed at runtime.
- The original [chords-db](https://github.com/tombatossals/chords-db) catalog remains unchanged. It is not the source of the supplemental fingerings.

`src/chords/extended-definitions.json` is shared by catalog generation, pitch validation, display names, search aliases, and browse categories. The audit compares formulas with Tonal base chords plus the added interval, then checks custom dictionary registrations. Minor 13th deliberately permits the 11th in its allowed pitch set, while Tonal's default minor-13th dictionary spelling omits it.

| Suffix | Required intervals | Optional intervals |
| --- | --- | --- |
| m13 | b3, b7, 13 | root, fifth, ninth, eleventh |
| m11add13 | b3, b7, 11, 13 | root, fifth, ninth |
| 7add13 | 3, b7, 13 | root, fifth |
| maj7add13 | 3, 7, 13 | root, fifth |
| m7add13 | b3, b7, 13 | root, fifth |
| add13 | root, 3, 5, 13 | none |
| madd11 | root, b3, 5, 11 | none |
| madd13 | root, b3, 5, 13 | none |

`Bm11 add13` has the full pitch vocabulary B, D, F#, A, C#, E, G#. Its six-string grips must preserve D, A, E, and G#. For example, `xx2234` plays E3, A3, D4, G#4 and explicitly reports omitted root, fifth, and ninth. This is a rootless voicing; it does not sound a B bass note. Minor 13th and minor 11th added 13th remain separate groups because the latter requires the eleventh.

## Supplemental fingering review

The 16 C-root seed grips in `vendor/chords/supplemental.json` are original MyChords arrangements, not copied diagrams or a claim of endorsement by the references above. They are available under the MIT license in `vendor/chords/SUPPLEMENTAL-LICENSE`.

Each grip uses four adjacent strings, a span of at most two frets, and at most four fingers. Fingering review checks ascending finger placement, repeated-finger barres, and clearance over every intervening string. Muted strings outside the grip are not strummed. Rootless grips are intentional and their omissions are displayed. These are coordinate and fingering reviews, not a physical guitarist trial; comfort varies by hand and neck position.

Only closed grips are transposed, preserving their fingers and barres. The importer places each seed in every root, adds octave shifts within fret 22, and derives omissions from actual pitches. Source hashes and seed-to-result references are recorded in `docs/catalog-coverage.json`.

## Verification and compatibility

Run `npm run catalog:import`, `npm run catalog:audit`, `npm test`, `npm run lint`, `npm run build`, and `npx playwright test e2e/extended-chords.spec.ts`. Importing twice must leave generated bytes unchanged.

The audit checks pitch formulas, defining colors, omissions, finger/barre geometry, and at least two positions per family/root. A normalized SHA-256 fingerprint protects all 4,968 pre-existing voicings. Any intentional future legacy correction must review the fingerprint change rather than update it automatically. Existing storage and share formats remain at version 1, retaining exact voicing IDs. An older app build cannot resolve newly introduced IDs until it updates.
